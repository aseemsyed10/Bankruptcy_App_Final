# Bankruptcy Risk Explorer

Full-stack educational bankruptcy classifier using logistic regression, feature selection, SHAP explainability, Great Expectations data validation, a FastAPI inference service, and a Streamlit dashboard.

## Run

With Docker: `docker compose up --build` then visit http://localhost:8501 (UI), http://localhost:8000/docs (API).

Without Docker (Python 3.11): install `requirements.txt`; run `python train.py`, `python explain.py`, and `uvicorn main:app --reload`. In a second terminal install `frontend/requirements.txt`, then `streamlit run frontend/app.py`.

Training reads `data.csv` with `Bankrupt?` as target. The initial holdout is stratified; training-only cross-validation chooses the number of selected features and logistic regression regularization strength. `artifacts/model.joblib` bundles the imputer, scaler, selected features, and classifier with the original feature order. `artifacts/metrics.json` contains holdout and CV scores. `artifacts/shap_beeswarm.png` is generated by `python explain.py`.

Validation: `validation.py` uses Great Expectations 0.18 to check row counts, required target, valid binary labels and predictor types. Failed validation aborts training. Run `pytest -q` for smoke tests.

The frontend accepts a named-feature CSV or a single manually entered company and displays class, probability and local log-odds SHAP contributions. Default zero inputs are placeholders, **not realistic company financial values**. Probability estimates are uncalibrated and must not be used as financial advice.

### API

`GET /features` returns required financial names; `POST /predict` expects `{"values": {"feature name": 0.1, "other feature": 0.2}}` with *every exact feature name* and returns prediction, probability and (where available) SHAP contributions. API errors on missing or extra predictors.
